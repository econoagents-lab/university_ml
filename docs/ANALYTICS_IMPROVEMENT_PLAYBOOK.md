# ANALYTICS_IMPROVEMENT_PLAYBOOK

## Lo que más debes mejorar

1. Cohortes reales: lead → separación → minuta → caída.
2. Conversión por tiempo: days_to_minuta, days_to_caida, survival/hazard.
3. Capacidad comercial como restricción: precision@capacity.
4. Unit economics por canal.
5. Stock como inventario económico: edad, precio, valorización, absorción.
6. Cobranza como conversión final: venta → caja.
7. NLP de motivos de caída.
8. Baseline comercial defendible antes del ML.
9. Calibración de probabilidades.
10. ROI neto del sistema.

## Regla

Todo análisis debe terminar en una decisión:
- llamar a alguien,
- cambiar precio,
- mover campaña,
- destrabar cobranza,
- ajustar stock,
- reentrenar o recalibrar,
- o retirar una métrica.
