# Client Data Room Policy

Yo no coloco CRM crudo en el data room de cliente. Solo comparto:

- payload agregado,
- one-pager,
- landing,
- paquete JSON de demo,
- checklist de privacidad,
- rutas públicas seguras.

Prohibido: clientes, DNI, teléfono, email, dirección, códigos crudos, credenciales y `.env`.
