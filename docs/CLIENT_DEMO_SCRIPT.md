# Client Demo Script

## Apertura
Hoy no vamos a revisar reportes. Vamos a ver cómo una inmobiliaria convierte datos comerciales en decisiones accionables.

## Recorrido
1. Dashboard público: visión segura para gerencia o cliente externo.
2. Catálogo: todos los productos de decisión disponibles.
3. Riesgo y acciones: operaciones priorizadas por impacto.
4. Feedback: medición de qué ocurrió después de intervenir.
5. Política: capacidad, SLA y escalamiento.

## Cierre
La promesa es una empresa que aprende de cada operación comercial, no una empresa que solo mira números al cierre del mes.
