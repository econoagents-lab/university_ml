# v2.3 · Client Proposal & Contract Automation

Esta versión convierte cada demo multi-tenant en una propuesta comercial lista para conversar con un cliente.

## Qué produce

- Propuesta ejecutiva por cliente.
- Alcance de implementación.
- Contrato de métricas.
- Pricing sugerido.
- Checklist de onboarding.
- Plan de 30 días.
- Paquete JSON para API/demo.

## Principio de gobierno

El contrato de métricas evita vender humo: cada módulo debe tener owner, decisión habilitada, grano, frecuencia y regla de privacidad.
