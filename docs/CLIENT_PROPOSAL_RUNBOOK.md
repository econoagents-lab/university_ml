# Runbook de propuestas cliente

1. Revisar `config/client_tenants.yml`.
2. Revisar `config/client_proposals.yml`.
3. Ejecutar `python scripts/120_run_v23_client_proposal_and_contract_automation.py`.
4. Abrir `reports/client_proposals/proposal_index.html`.
5. Revisar propuesta, scope, contrato y pricing.
6. Ajustar paquete recomendado si hace falta.
7. Enviar one-pager/propuesta, no enviar data ni payloads internos.
