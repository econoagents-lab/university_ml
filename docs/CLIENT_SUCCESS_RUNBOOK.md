# Client Success Runbook

## Uso operativo

1. Ejecutar v2.4 para generar work orders e invoices.
2. Ejecutar v2.5 para calcular salud y renovación.
3. Revisar tenants en rojo o amarillo.
4. Preparar QBR con `qbr_brief.md`.
5. Actualizar adopción real cuando existan métricas de uso.
6. Proponer upsell solo cuando salud y valor realizado sean defendibles.

## Decisión

- Green: renovar y expandir.
- Yellow: reforzar adopción antes de renovar.
- Red: plan de rescate churn.
