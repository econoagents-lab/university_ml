# Demo para congreso de data science v1.0

## Tesis

Un modelo aplicado a CRM inmobiliario no debe presentarse solo como métrica predictiva, sino como sistema de decisión gobernado.

## Secuencia

1. Business framing: riesgo de caída y valor económico.
2. Data contracts: definición de separación, minuta, caída y model-ready.
3. Anti-leakage: fecha_caida solo para target/auditoría, nunca para X.
4. Modeling: baseline, champion/challenger y registry.
5. Evaluation: ROC, PR, lift, calibration y confusion matrix.
6. Monitoring: drift, prediction PSI y política de retraining.
7. Decision API: cola operativa, feedback y readiness.
