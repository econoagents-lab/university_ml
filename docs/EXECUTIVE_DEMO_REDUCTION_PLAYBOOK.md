# Executive Demo Reduction Playbook

## Objetivo

Convertir una demo con demasiadas rutas en una experiencia de 6 puertas.

## Puertas recomendadas

1. Executive Value Brief
2. Public Decision Dashboard
3. Risk Action Queue
4. Real Marts / Cohortes
5. Action Feedback
6. Experiment Policy

## Mensaje prohibido

“No vendemos un modelo que predice caídas con alta precisión.”

## Mensaje recomendado

“Vendemos un sistema que prioriza riesgo comercial, ordena acción, captura feedback y convierte aprendizaje en política.”
