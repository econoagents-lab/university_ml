# Demo ejecutiva v1.0

## Guion de 7 minutos

1. Problema: separaciones en riesgo de caída afectan ventas y caja.
2. Solución: modelo de priorización con contratos, anti-leakage y registry.
3. Dashboard: cola diaria por prioridad, responsable y valor esperado en riesgo.
4. API: endpoints para gerencia, asesores, feedback y metadata.
5. Gobierno: champion/challenger, drift, retraining policy y production readiness.
6. Acción: revisar P0/P1 diariamente y registrar resultado.
7. Cierre: el modelo no reemplaza al gerente; organiza el seguimiento con trazabilidad.
