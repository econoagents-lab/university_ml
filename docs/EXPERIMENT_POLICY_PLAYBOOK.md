# Experiment Policy Playbook

## Decisiones tomadas

- P0 siempre se trata; no se deja en control por ética comercial.
- P1 puede tener control estratificado para medir impacto sin abandonar operaciones críticas.
- P2 se monitorea y escala si aumenta riesgo o valor esperado en riesgo.
- La política solo se escala cuando compliance y feedback tienen calidad suficiente.

## Reglas operativas

| Prioridad | SLA | Holdout | Acción |
|---|---:|---|---|
| P0 | 4h | No | llamada el mismo día + escalamiento a jefatura |
| P1 | 24h | Sí, controlado | contacto prioritario + seguimiento 48h |
| P2 | 72h | Sí | monitoreo + revisión semanal |

## Cómo usarlo en comité

1. Revisar capacidad diaria recomendada.
2. Revisar compliance de tratamiento.
3. Revisar segmentos con señal positiva.
4. Ajustar umbrales P0/P1 y SLA.
5. Mantener feedback 7d/30d como requisito de aprendizaje.
