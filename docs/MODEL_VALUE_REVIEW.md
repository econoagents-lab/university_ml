# MODEL_VALUE_REVIEW

## Tesis

El modelo de riesgo no debe venderse como oráculo. Debe venderse como sistema de priorización gobernado.

## Revisión obligatoria

- ¿El modelo supera reglas simples?
- ¿El top 20/top 50 concentra caídas?
- ¿El score está calibrado?
- ¿El threshold responde a capacidad comercial real?
- ¿El feedback confirma que actuar sobre P0/P1 cambia resultados?

## Métricas core

- Average Precision
- Lift Top Decile
- Precision@20
- Recall@50
- Recall@Capacity
- Brier Score
- Calibration Gap
- Valor en riesgo @ Capacity
