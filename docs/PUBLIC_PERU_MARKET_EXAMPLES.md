# Public Peru Market Examples

Yo uso tres inmobiliarias peruanas como ejemplos públicos de mercado para mejorar la landing online:

- Besco
- Edifica
- Paz Inmobiliaria

## Regla de gobierno

Estas compañías no son clientes reales del sistema. Se usan como referencias públicas para demostrar cómo el producto leería perfiles distintos: alto volumen, ubicación premium y portafolio urbano.

## Dónde cambiar

```text
config/public_peru_client_examples.yml
```

Cuando exista una base histórica real, reemplazar estos bloques por un payload CRM agregado por tenant. Railway debe seguir sirviendo solo agregados.

## No permitido

- clientes
- documentos
- teléfonos
- emails
- direcciones
- códigos de proforma
- códigos de unidad
- credenciales
