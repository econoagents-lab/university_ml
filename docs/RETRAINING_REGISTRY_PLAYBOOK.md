# Retraining Registry Playbook

## Mantra

Un modelo sin registry es una predicción sin memoria.

## Flujo

```text
model-ready dataset
→ dataset registry
→ train challengers
→ compare champion/challenger
→ retraining policy
→ promotion decision
→ endpoint metadata
→ congress figures
```

## Reglas

1. No registrar modelo sin dataset version.
2. No promover challenger sin comparación.
3. No reentrenar por ansiedad: solo por drift, feedback, antigüedad o degradación.
4. No exponer raw CRM en el ZIP: CRM-first no significa data leak.
5. El pack de congreso usa agregados, métricas y gráficos exportables.
