# Sales Demo Playbook v2.0

## Objetivo
Mostrar que el sistema no termina en dashboard: termina en una decisión comercial medible.

## Demo recomendada
1. Abrir `/production/health` para probar que la API vive.
2. Abrir `/metadata/productized-os` para ver estado del producto.
3. Abrir `/public/decision-dashboard` para mostrar demo externa sin PII.
4. Abrir `/dashboard/catalog` para enseñar el catálogo de dashboards.
5. Abrir `/dashboard/action-feedback` para enseñar acción y feedback.
6. Abrir `/dashboard/experiment-power-policy` para enseñar política comercial.

## Frase de cierre
El valor no está en predecir caídas. El valor está en decidir a quién llamar, medir si la acción funcionó y ajustar la política comercial.
