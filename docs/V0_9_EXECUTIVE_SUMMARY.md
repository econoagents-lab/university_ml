# v0.9 Decision Dashboard API - Executive Summary

## Qué cambió

La fábrica ahora convierte scoring de riesgo en una cola de decisión diaria.

## Capacidades

- Cola priorizada por P0/P1/P2/P3.
- KPIs ejecutivos de valor esperado en riesgo.
- Agregados por proyecto y asesor.
- Dashboard HTML local.
- API para Power BI, Flask, front-end o agentes.
- Brief ejecutivo reproducible.

## Valor

El modelo deja de vivir en el laboratorio y se convierte en una herramienta operativa para proteger ventas, caja y seguimiento comercial.
