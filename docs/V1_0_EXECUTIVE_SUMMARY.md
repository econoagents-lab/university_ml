# v1.0 Executive Summary

Machine Learning University v1.0 convierte el caso de riesgo de caída en un sistema productivo local/Railway-ready:

- score de riesgo,
- cola diaria de decisión,
- dashboard ejecutivo,
- feedback loop,
- registry de modelos,
- readiness report,
- auth opcional,
- contratos SQL para Supabase/Postgres.

La versión es CRM-first y mantiene modo demo para enseñanza segura.
