# v1.3 Executive Summary

La versión v1.3 agrega gobierno de dashboards y parámetros para convertir la fábrica en un sistema configurable.

## Valor

- Catálogo máximo de 60 dashboards posibles.
- Columna `Donde cambiar` para cada producto de decisión.
- Parámetros centrales para riesgo, privacidad, RAG, Railway, mercado y modelos.
- Decisiones recomendadas ya codificadas.
- Tests para evitar exposición pública indebida.

## Decisión clave

La arquitectura pública queda blindada: Railway sirve solo agregados; Lenovo opera el CRM completo; GitHub publica artifacts agregados o anonimizados.
