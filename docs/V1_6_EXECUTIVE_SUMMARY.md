# V1.6 Executive Summary · Real Mart Expansion

La versión v1.6 convierte la inteligencia de dashboards en una capa de marts reales. El objetivo no es mostrar más números: es separar evidencia oficial de proxy.

## Cambios principales

1. Marts reales para funnel, cobranza, stock, pricing, mercado y feedback.
2. Reporte `PROXY_VS_OFFICIAL_GAP.md` para ver qué queda por conectar.
3. Validación automática de privacidad en todos los marts exportados.
4. Enriquecimiento del Dashboard Metrics Engine con familia `real_marts`.
5. Endpoints API para metadata y reporte de marts reales.

## Valor comercial

La gerencia puede preguntar: “¿Esto es proxy o métrica oficial?” y el sistema responde con artefacto, fuente y estado.
