# v2.5 Executive Summary

La versión v2.5 convierte la máquina comercial en un sistema de postventa inteligente. Ya no basta con vender y facturar: ahora cada tenant tiene salud, adopción, riesgo de churn, plan de QBR, oportunidades de upsell y recomendación de renovación.

La señal central es el health score. El sistema combina adopción, avance de hitos, pagos, QBR y valor realizado para clasificar tenants en green, yellow o red.

La regla ejecutiva es simple: green expande, yellow se rescata, red requiere intervención ejecutiva.
