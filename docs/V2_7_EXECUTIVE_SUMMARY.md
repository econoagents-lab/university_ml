# V2.7 Executive Summary

v2.7 soluciona los principales problemas detectados por auditoría:

- El P0/P1 anterior podía abarcar casi toda la cola. Ahora se restringe por capacidad.
- El modelo tenía señales débiles. Ahora el brief obliga a comunicarlo como ranking gobernado.
- El dashboard público podía exponer nombres de proyectos. Ahora se anonimiza por defecto.
- La demo estaba dispersa. Ahora hay una página ejecutiva única.

Resultado: el sistema deja de parecer solo impresionante y empieza a ser más defendible económicamente.
