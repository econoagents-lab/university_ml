# Arquitectura

```text
data/sample -> notebooks -> src/mlu -> models -> api -> feedback
```

## Flujo

1. Generar/leer datos.
2. Validar contrato.
3. Entender negocio.
4. Explorar patrones.
5. Separar entrenamiento/prueba.
6. Entrenar modelo.
7. Predecir casos no vistos.
8. Evaluar errores.
9. Interpretar variables.
10. Servir predicción por API.
11. Medir acción y feedback.

## Mejoras incluidas

- Baseline económico antes del modelo.
- Contratos de datos y features.
- Model card.
- API productiva mínima.
- Tests.
- Control de avance.
- Data sintética segura.
- Valor esperado en riesgo.
- Preparación para drift y feedback loop.
