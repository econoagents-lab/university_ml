# Glosario

- **X**: Variables que el profesor observa.
- **y**: Respuesta histórica que el profesor intenta aprender.
- **fit**: Momento en que el profesor estudia.
- **predict**: Momento en que el profesor responde.
- **predict_proba**: El profesor no solo responde; expresa incertidumbre.
- **Precision**: De los casos que marqué como riesgo, cuántos realmente eran riesgo.
- **Recall**: De todos los riesgos reales, cuántos encontré.
- **ROC AUC**: Capacidad general para ordenar casos riesgosos por encima de casos sanos.
- **Data contract**: Pacto que evita que la métrica se vuelva discutible.
- **Model card**: Documento de identidad del modelo.
