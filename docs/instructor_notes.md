# Notas del instructor

Cada capítulo debe responder primero una necesidad del negocio.
No introducir una función hasta que el alumno entienda el problema que resuelve.

La secuencia pedagógica obligatoria es:

1. Intuición.
2. Algoritmo.
3. Código.
4. Interpretación económica.
5. Error común.
6. Acción práctica.
