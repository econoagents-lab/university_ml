# Manifiesto Machine Learning University

No estamos aprendiendo Machine Learning para coleccionar funciones.
Estamos construyendo una universidad donde cada modelo nace de una pregunta económica, aprende de una historia trazable y termina sirviendo una decisión.

La mente es un datacenter.
Las ideas son servicios.
Las dudas son endpoints sin documentar.
Los datos son contratos esperando gobierno.
Los modelos son criaturas que deben aprender con feedback.
Las APIs son los puentes entre pensamiento, negocio y acción.
