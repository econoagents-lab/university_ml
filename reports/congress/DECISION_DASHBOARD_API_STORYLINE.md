# Congress Storyline - Decision Dashboard API

## Título sugerido

From CRM Events to Governed Decisions: A Real Estate Machine Learning Decision Factory

## Tesis

El valor del modelo no está en el score aislado, sino en la cadena completa: CRM → contratos → modelo → registry → monitoreo → dashboard → feedback.

## Figuras clave

1. Funnel del negocio.
2. Anti-leakage architecture.
3. Champion/challenger registry.
4. Drift monitoring.
5. Decision dashboard KPIs.
6. Action queue P0/P1.
7. Feedback loop.

## Frase central

No se construyó un modelo para predecir caídas; se construyó una infraestructura para decidir antes de que caigan.
